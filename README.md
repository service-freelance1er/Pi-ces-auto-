# Projet Boutique Dropshipping

Démo complète d'un site statique multi-pages sans base de données ni serveur.

## Technologies testées
- HTML5 sémantique
- CSS moderne (Grid, responsive, variables, prefers-reduced-motion)
- JavaScript ES Modules
- JSON local
- LocalStorage pour le panier
- Recherche et filtres côté client
- Dark / Light mode
- PWA (manifest + Service Worker)
- Design responsive et accessibilité de base

## Lancer
Utilisez un serveur statique local (par exemple l'extension Live Server de VS Code) afin que le chargement JSON et le Service Worker fonctionnent correctement.
